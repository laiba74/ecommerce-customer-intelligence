## Project Overview

### Project Title
E-commerce Customer Experience & Delivery Performance Analysis

### Objective
Analyze how delivery performance, geography, and order value impact customer satisfaction and sales performance in an e-commerce marketplace.

### Business Questions
1. How are revenue, orders, and average order value changing over time?
2. How does delivery performance affect customer review scores?
3. Which states have the highest late delivery rates?
4. How do different order value segments compare in delivery and reviews?
5. Which sellers perform best and worst in delivery and customer satisfaction?
